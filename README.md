# getFish 🎣

물고기가 동그라미 위를 지나가는 순간 **딱!** 눌러서 체력을 깎으면 낚이는 2D 웹 낚시 게임이에요.
옛날 모바일 낚시 게임의 초창기 손맛(타이밍 누르기, 장비 파밍, 도감 모으기)을 떠올리며 새로 만들었어요.

**하러 가기:** https://mhyoo-games.github.io/getFish/

## 낚시하는 법
1. **던지기** — 한 번 누르면 힘 게이지가 오르내려요. 오른쪽 노란 **NICE** 구간에서 한 번 더 누르면 멀리 던져요. 멀리 던질수록(비거리 m) 드문 물고기가 더 오고 크기도 커지는 쪽으로 기울어요. NICE면 싸움 시간 +2초. 장비의 **멀리 던지기**(낚싯대·줄·찌·선장 모자)가 NICE 구간을 넓히고 효과를 키우며 입질도 빨라져요. 큰 버튼, Space, 화면 누르기 모두 돼요.
2. **입질** — 찌가 쑥 들어가고 `!`가 뜨면 바로 눌러서 챔질.
3. **타이밍 싸움** — 위쪽 줄에서 물고기가 왔다 갔다 해요. 동그란 과녁 위에 올 때 누르면 체력이 깎여요. 가운데일수록 1.5배(PERFECT), 금빛 동그라미는 2배.
4. **조심** — 빈 곳을 누르면 하트(줄 버팀)가 줄어요. 하트가 다 닳거나 시간이 끝나면 도망가요. 체력이 30% 아래면 물고기가 화가 나서 빨라져요.

## 손맛
- **진동(타격감):** 누를 때마다 휴대폰이 떨려요. 단추는 톡, 힘 게이지 시작·던지기는 가볍게, 챔질은 묵직하게, 맞히면 탁, PERFECT는 더 세게, 금빛은 두세 번 연달아, 빗나가면 길고 둔하게, 입질·잡았을 때·레벨 업은 각자 다른 리듬. 위쪽 📳 단추로 켜고 끌 수 있어요.
  - 안드로이드는 진동 패턴 그대로, 아이폰(Safari 18 이상)은 진동 기능이 없어서 숨겨 둔 스위치의 시스템 햅틱으로 톡톡 울려요(아이폰은 손으로 누른 순간에만 울려서, 입질처럼 저절로 오는 진동은 안 와요).
- 맞힌 자리에 물결 고리가 퍼지고 줄이 번쩍이며, PERFECT·금빛은 아주 잠깐 멈춰서 "딱!" 하는 느낌을 줘요. 빗나가면 빨갛게 번쩍.
- 잡으면 물고기가 물보라와 함께 튀어 올라 빙글 돌며 화면 가운데로 오고, 빛이 퍼지며 "낚았다!"와 등급 도장이 찍혀요. 새 도감·드문 물고기·S 이상이면 꽃가루가 내려요. 낚시꾼은 낚싯대를 번쩍 들어요.

## 배경음
「바닷바람 메모리」 — 90년대 J-pop 느낌의 경쾌한 8비트 곡을 새로 지었어요(멜로디·코드 진행 모두 새로 만듦). 드럼·베이스·일렉 피아노·스트링·노래하듯 비브라토가 들어가는 리드, 인트로 → A → B → 후렴 → 후렴2 구성(약 1분 40초 반복). 바다마다 조를 옮기고 심해는 조금 차분하게 연주해요. 모두 브라우저에서 합성해요.

## 바다 4곳 · 물고기 52종
| 바다 | 분위기 | 보스 |
|---|---|---|
| 햇살 선착장 | 잔잔한 아침 | 수염 영감 (거대 메기) |
| 산호초 바다 | 알록달록 산호 | 파도 날개 (왕가오리) |
| 안개 협만 | 차가운 북쪽 바다 | 서리왕 (얼음 상어) |
| 심해 해구 | 빛나는 깊은 바다 | 심연의 등불왕 (아귀) |

- 바다마다 13종: 흔함 4 · 보통 3 · 드묾 3 · 아주 드묾 2 · 보스 1. 보스를 잡으면 다음 바다가 열려요.
- 보스는 **황금 미끼**로 '보스 도전'을 눌러 불러요 (상점·드랍·도감 세트 보상).
- **크기 등급** C · B · A · S · SS: 같은 물고기 안에서 몇 % 크기인지로 정해요(SS는 약 3%). 등급이 높을수록 체력·빠르기·값이 올라가요.

## 레벨 · 칭호
- 잡을 때마다 경험치(물고기 등급 × 바다 × 크기 등급, 새 도감이면 +30). 레벨이 오르면 동전(레벨 × 100)을 받고, 2레벨마다 힘 +1, 15레벨마다 하트 +1. 최고 레벨 50.
- 칭호 21개: 레벨(5·10·20·30·40·50), 도감 수(10·26·52), 바다별 도감 완성, 보스(1·4), SS 등급(1·10종), 잡은 수(100·500), 나이스 캐스팅 30번. 하나를 골라 달면 그 칭호의 작은 효과가 들어가요. 위쪽 Lv 단추나 T 키로 열어요.

## 만든 방식
- 빌드 없는 정적 웹 페이지(ES 모듈). 물고기 52종·바다·캐릭터 그림은 모두 canvas로 직접 그리고, 수채화 그림책 느낌으로 한 번 더 칠해요(`paintify`: 물감 번짐, 따뜻한 햇빛과 보랏빛 그늘, 붓 자국, 종이 결, 가장자리 물감 고임, 위쪽 햇빛 테두리·아래쪽 바다 반사광). 한 번 칠한 그림은 저장해 두고 다시 써요.
- 소리는 녹음 파일 없이 브라우저에서 합성해요(바다마다 다른 잔잔한 가락 + 효과음).
- `js/data.js` 데이터 · `js/game.js` 규칙(순수 계산) · `js/draw.js` 그림 · `js/main.js` 화면 · `js/sound.js` 소리.
- 테스트: `node tests/data.test.mjs`, `node tests/logic.test.mjs` (자동 낚시꾼으로 장비별 승률 확인). GitHub Actions에서 테스트를 통과해야 배포돼요.
- `tools/gallery.html`: 물고기 52종과 아바타를 한 장에 모아 보는 확인용 페이지.
