# 토이피쉬 🎣

장난감 바다에서 장난감 낚시꾼이 장난감 물고기를 낚는 2D 웹 낚시 게임이에요. 물고기가 동그라미 위를 지나가는 순간 **딱!** 눌러서 체력을 깎으면 낚여요.
(저장소 이름과 주소는 예전 이름 그대로 `getFish`예요.)
옛날 모바일 낚시 게임의 초창기 손맛(타이밍 누르기, 장비 파밍, 도감 모으기)을 떠올리며 새로 만들었어요.

**하러 가기:** https://mhyoo-games.github.io/getFish/

## 낚시하는 법
1. **낚시꾼 고르기** — 처음에 남자·여자 낚시꾼 중 하나를 골라요(꾸미기 → 캐릭터에서 언제든 바꿔요).
2. **던지기** — 한 번 누르면 별이 막대 위를 왔다 갔다 해요. **가운데**에서 한 번 더 누르면 PERFECT! 가운데에 가까울수록 PERFECT · GREAT · GOOD · 아쉬워요 순서로, 잘 던질수록 멀리 날아가 드문 물고기와 보스가 더 오고 싸움 시간도 늘어요. 깊은 바다일수록 별이 빨라지고, 장비의 **멀리 던지기**가 가운데 구간을 넓혀요.
3. **거두기** — 던진 뒤 입질 전까지 **↩ 거두기**(X · Esc)로 낚싯대를 거둘 수 있어요. 물고기가 먹지 않은 미끼는 돌려받아요.
4. **입질** — 찌가 쑥 들어가고 `!`가 뜨면 바로 눌러서 챔질.
5. **타이밍 싸움** — 물고기가 동그란 과녁 위에 올 때 누르면 체력이 깎여요. 가운데일수록 1.5배(PERFECT), 금빛 과녁은 2배. 빈 곳을 누르면 하트(줄 버팀)가 줄어요.

## 보스
- 보스는 낚시하다가 **우연히** 나타나요. 미끼마다 확률이 달라요(맨 바늘 0.4% · 지렁이 1.2% · 반짝 루어 3.5% · 용궁 구슬 12% · 황금 미끼 22% 등). 가운데로 잘 던질수록, 행운이 높을수록, 보스를 오래 못 만났을수록 조금씩 더 자주 나와요. 지금 미끼의 보스 확률은 아래쪽 미끼 단추에 보여요.
- 보스가 물면 하늘이 어두워지고 물이 솟구치며 거대한 보스가 떠올라 이름판이 뜨고, 보스 음악으로 바뀌어요. 싸우는 동안 수면 아래로 커다란 그림자가 맴돌아요.
- 보스 체력이 60%·30% 아래로 내려가면 **포효**하며 화면이 흔들리고 더 빨라져요. 보스를 잡으면 다음 바다가 열려요.

## 만든 방식
- 빌드 없는 정적 웹 페이지(ES 모듈). 게임 화면은 2D canvas이고, 낚시꾼과 물고기만 three.js로 3D를 그려 2D 화면에 붙여 넣어요.
  - 낚시꾼: Kenney Mini Characters 모델(뼈대 애니메이션: 들고 있기·휘두르기·당기기·기뻐하기)에 모자·낚싯대 같은 소품을 상자로 만들어 붙였어요.
  - 물고기: 같은 장난감 느낌이 나게 마디진 상자를 모양 곡선대로 눌러 만들고, 면마다 무늬를 칠해요. 보스는 금 왕관과 빛나는 눈. 한 번 그린 물고기는 저장해 두고 다시 써요.
  - 3D를 못 쓰는 브라우저에서는 예전 2D 그림으로 그려요.
- 소리는 녹음 파일 없이 브라우저에서 합성해요(바다마다 조를 옮기는 배경음, 보스 음악, 효과음).
- `js/data.js` 데이터 · `js/game.js` 규칙(순수 계산) · `js/toy3d.js` 3D 그림 · `js/draw.js` 바다·2D 그림 · `js/main.js` 화면 · `js/sound.js` 소리.
- 테스트: `node tests/data.test.mjs`, `node tests/logic.test.mjs` (자동 낚시꾼으로 장비별 승률, 보스 확률, 던지기 판정 확인). GitHub Actions에서 테스트를 통과해야 배포돼요.
